# Agent 技术实战：从零读懂三大 Agent 代码库

> 面向普通技术人员，用最通俗的语言，通过三个真实、可运行的 Agent 代码库，
> 由浅入深地掌握 Agent（智能体）技术的核心原理与工程实践。

---

## 这本书讲什么

近两年，"Agent"成了技术圈最热的词之一。你会看到各种名词：Agent Loop、
工具调用（Tool Calling）、MCP、系统提示词（System Prompt）、沙箱（Sandbox）、
会话持久化……这些词背后到底是什么？一个能自动写代码、改文件、跑命令的"智能体"，
它的"大脑"里到底在跑一个什么样的循环？

市面上讲 Agent 的书大多停留在概念层，讲"prompt 怎么写、Agent 框架怎么用"。
这本书不一样：我们直接打开三个真实的、开源的、可运行的 Agent 代码库，
逐行读它们最核心的推理代码，回答三个问题：

1. **Agent 是怎么"想"的** —— 推理循环（agent loop）到底长什么样？
2. **Agent 是怎么"做"的** —— 工具（tool）如何被调用、执行、回传？
3. **Agent 是怎么"活"下来的** —— 会话、记忆、安全、可观测性如何支撑它长期工作？

我们选择的三条代码，代表三种完全不同的工程路线，对照着读收获最大：

| 代码库 | 语言 | 定位 | 适合学习什么 |
|--------|------|------|--------------|
| **pi** | TypeScript（Bun） | 精简、可读性优先的 Agent 运行时 | 最小可读的推理循环、模型统一抽象 |
| **dsh（DeepSeek Harness）** | TypeScript | 插件化、企业级的 Agent 框架 | 插件架构、会话日志、能力切分 |
| **codex（OpenAI Codex）** | Rust | 生产级、严谨的 Agent CLI | 容错重试、上下文压缩、沙箱安全 |

同一个概念，比如"推理循环"，我们会先在 pi 里看它最朴素的样子，
再在 dsh 里看它如何被插件系统切分，最后在 codex 里看生产环境如何加满"保险丝"。

## 这本书适合谁

- **普通后端 / 前端工程师**：会写代码，但没深入看过 Agent 内部实现；
- **想转型 Agent 开发的工程师**：想知道"从哪下手、该读哪些代码"；
- **刚接触 Agent 框架的使用者**：想从"会用"升级到"懂原理"；
- **架构师 / 技术负责人**：想评估不同 Agent 框架的取舍，选型或自研。

阅读门槛：**会读 TypeScript 或 Rust 其中一种即可**。本书不要求你懂大模型内部的
Transformer 结构、注意力机制等原理——我们把模型当作一个"黑盒 API"来使用和讲解。

## 阅读路线

```
基础篇（第 1–4 章） ──► 核心篇（第 5–9 章，重点） ──► 进阶篇（第 10–13 章）
      │                        │                          │
      └────────────────────────┴──────────────────────────┴──► 实践篇（第 14–15 章）
```

- **只想快速建立直觉**：读第 1、5 章 + 第 9 章对比即可。
- **想深入代码**：按顺序读第 6、7、8 章，这是全书"代码精读"的核心，配一个编辑器打开
  对应代码库边读边查。
- **想动手实践**：读完第 6 章后就可以先跳到第 14 章，写一个你自己的最小 Agent。

## 如何阅读代码精读章节

第 6、7、8 章是全书最长的三章。建议：

1. 先读该章的"整体结构"小节，在脑中建立函数调用图；
2. 再按"逐步解读"小节的顺序，把代码逐行读一遍，对照图表理解；
3. 最后做"动手练习"，改动代码、观察行为变化，再回来看讲解。

书中的代码片段都标注了来源文件路径与仓库，方便你在本地打开原文件对照。
代码可能随版本演进，本书基于 2026-08 的版本编写。

## 本书特色（作者补充的编写约定）

1. **先讲生活，再讲代码**：每个概念先用一个生活化的类比建立直觉，再落到代码。
2. **代码精读带行号**：核心代码逐段标注，配合"这一行在做什么、为什么"的解读。
3. **三库对照**：同一概念在三个代码库里如何实现，用对照表 + 分节展开。
4. **每章固定结构**：本章目标 → 引入 → 核心概念 → 代码精读（如有）→ 三库对照 →
   动手练习 → 本章小结。
5. **术语即索引**：所有术语首次出现时加粗并给出通俗解释，并在附录 A 汇总。
6. **图解优先**：复杂流程用 mermaid 图（思维循环、状态机、调用链）表达。
7. **练习 + 参考答案**：每章有思考题，附录 D 提供参考答案。
8. **可验证性**：书中引用的每个关键行为都尽量提供"你怎么亲手验证"的路径。
